# 拍立得转换 · 方向卡

## Spec（三版共用）
- 是什么：手机网页工具。上传或拍一张实体拍立得 → 自动找边框、拉正 → 调色修图（滤镜、亮度、色温、颗粒、保留白框）→ 保存到相册。
- 谁用、在哪用：手里拿着几张 instax / Polaroid 的年轻人，单手拿手机在桌前操作。
- 核心信息：①照片本身是主角 ②一眼看出下一步该点哪里 ③调完能存进相册
- 情感基调：轻松、有点手作感，不是专业后期软件的压迫感
- 输出格式：手机竖屏，宽 390；方向稿每版展示两屏（扫描确认 / 调色编辑）
- 已知约束：用户偏好 App 背景纯色、不要渐变/光晕，每屏少放东西，主操作一眼可见（learn.py L4）
- 素材：示例照片 Palanga 09（Wikimedia Commons，Palanga 海滩，CC BY-SA 4.0），T0 档

## 六个候选

### A · 最佳设计师｜葛西薰（克制）
- 借的：大面积留白里只放一张照片；明朝体小字；颜色几乎不用，靠位置和字号排层级
- 主角素材：拍立得实物（带白框）放在纸面中央，像相册里的一页
- 骨架：上 2/3 是照片，下 1/3 是一行滤镜名 + 一条细刻度，按钮只有「存入相册」
- 胆量：整屏没有一个色块按钮，主操作是一行加粗的黑字
- form：拍立得的白框本来就是「留白」，界面接着这块留白往外长

### B · 最佳设计师｜服部一成（大胆）
- 借的：错位、手写、贴纸感；一块饱和纯色底；元素故意不对齐但有节奏
- 主角素材：歪着贴在色底上的拍立得 + 一截胶带 + 白框底部手写日期
- 骨架：照片斜放占上半屏，下面是大圆角的滤镜「贴纸」和粗滑块
- 胆量：照片转 -4°，白框上的手写字可以直接编辑
- form：拍立得被人拿在手里、贴在本子上，这个动作就是界面

### C · 现实参照｜Halide（Apple Design Award 获奖相机 App）
- 借的：纯黑底 + 一种黄色只给当前参数；参数行 + 横向刻度尺 + 中心黄线
- 主角素材：照片 + 一条密集刻度尺
- 骨架：上照片，中参数行（滤镜/亮度/色温/颗粒），下刻度尺，底部大圆键「存」
- 胆量：调参不用滑块，用相机拨盘式刻度尺
- form：拍立得本来就是相机，调色就像在拨相机
- 备注：本次 WebSearch 不可用、本机没装 Python 版 playwright，参考板没截到，未亲眼看到原 App，规则取自风格库条目

### D · 现实参照｜Darkroom（iOS 照片编辑 App）
- 借的：深灰底、底部一排滤镜缩略图（每张都是自己的照片套上滤镜）
- 主角素材：照片 + 滤镜缩略图带
- 骨架：照片居中，下方缩略图横滑，再下面三个 tab
- 胆量：缩略图就是真预览
- form：选滤镜时看到的就是自己的照片
- 备注：未核实、未亲眼看到

### E · 秒数轮盘（S=19）｜App #8 键盘优先命令面板（Raycast 式）
- 借的：近黑底、单行列表、色块小图标、右侧键帽
- 骨架：照片下面是一张「操作列表」：滤镜、亮度、色温、颗粒、白框、存入相册
- 胆量：所有功能都是一行命令
- form：弱，题材和命令面板关系不大

### F · 秒数轮盘（S=19）｜东亚 #8 杉浦康平信息曼荼罗
- 借的：同心环盘、朱红圆点、环上刻度文字
- 骨架：照片下面一个半圆拨盘，外环是滤镜名，内环是参数
- 胆量：整个调色区是一枚圆盘
- form：拨盘和相机转盘呼应，但用力偏重

## 挑出的三张
- dir-1 = C Halide 拨盘（暗、精确、工具感）
- dir-2 = A 葛西薰 相册页（亮、安静、留白）
- dir-3 = B 服部一成 贴纸本（饱和纯色、手作、俏皮）

三张骨架不同（刻度尺 / 文字行 / 贴纸块），温度不同（冷暗 / 中性亮 / 暖饱和）。D 和 C 太像（都是暗色专业），E、F 的 form 偏弱或用力过头，留作备选。
