# Homepage motion / 首页动效

The visual references are [Bounce Cards](https://www.reactbits.dev/components/bounce-cards), [Tilted Card](https://www.reactbits.dev/components/tilted-card) and [Fade Content](https://www.reactbits.dev/animations/fade-content) from React Bits. They were reviewed on 2026-10-29. This app's CSS and JavaScript are independently authored for its existing single-file layout; no React Bits component source is incorporated or distributed.

- The existing paper stack settles into place once per page session. A rotation sends the front photo to the back: it lifts and slides right while still on top, then tucks behind as the left photo comes forward. The photo corners release and re-attach to the new front photo. A fine pointer entering the stack rotates once immediately and then every 1.8 seconds while it stays, with a small fan-out; leaving the stack stops the timer. Touch taps, clicks, Enter and Space rotate once; a click during hover rotation restarts the 1.8-second timer. Nothing rotates while the page is idle. Each visit starts with the last-focused personal photo in front, followed by up to two other recent photos without duplicates. A one-photo collection shows that photo without rotation; a two-photo collection rotates only those two. Stock photographs appear only when there are no personal photos. Mobile vertical scrolling stays native, and the home scroller clips the card's sideways swing instead of scrolling horizontally.
- Only a fine pointer on a hover-capable device changes the front card's tilt, capped at three degrees on each axis. Leaving the stack resets it. Touch and gyroscope input do not tilt the card.
- The headline, introduction and actions use a short entrance. Recent photo buttons reveal when they enter the home scroller. Content remains visible without IntersectionObserver or Web Animations support.
- Reduced motion cancels active decorative animations, resets pointer tilt, and turns off hover rotation and the hover fan. Taps, clicks and keys still rotate the photos, as an instant swap without animation. Changing the preference while the page is open takes effect immediately.
- Pointer events request at most one animation frame at a time; there is no idle animation loop. Leaving the home screen cancels its active animations and observer.
- All decoration is scoped to the home interface. Scanning handles, editor previews, saved metadata and exported photo pixels remain independent of these effects.

React Bits has its own [MIT + Commons Clause license](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md). The links above acknowledge the design references; the project does not bundle or present its custom effects as copies of the upstream components.
