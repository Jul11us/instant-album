# Bundled font notices

These unmodified license texts accompany the Google Fonts files copied into the desktop application.

- The eleven `*-OFL.txt` files come from `https://raw.githubusercontent.com/google/fonts/main/ofl/<family>/OFL.txt`, where `<family>` is the filename prefix.
- `specialelite-LICENSE.txt` comes from <https://raw.githubusercontent.com/google/fonts/main/apache/specialelite/LICENSE.txt> (Apache 2.0).

`scripts/prepare-web.mjs` copies these notices and the installed Three.js/Shaders MIT licenses into `app/vendor/licenses/`, and extracts the existing photograph credits from the root README into `app/vendor/IMAGE-CREDITS.md`. Electron's distribution also includes its own runtime notices.
